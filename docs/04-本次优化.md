# 本次优化说明

日期：2026-10-28

## 1. 结果页阅读模式

- 解析成功后隐藏首页右侧装饰图，进入「左侧阅读区 + 右侧 300px 媒体栏」布局。
- 左栏：标题、视频元信息、AI 总结、完整文案 tab。
- 右栏：封面、标题、画质选择、质量提示、下载进度、暂停/继续/取消、保存按钮。
- `1100px` 以下折成单列；手机端媒体栏折到顶部。
- 相关文件：`frontend/src/components/ResultWorkbench.tsx`、`frontend/src/workbench.css`。

## 2. 完整文案（AI 整理稿）

- 总结完成后，后台继续用同一份字幕/转写生成 Markdown 文章。
- 文章包含标题、分节小标题、段落、列表、引用；删除口头禅和重复，补全标点，保留事实与术语。
- 「完整文案」tab 支持复制全文、下载 `.md`。
- 长转写分段整理；最长处理 `SUMMARY_ARTICLE_MAX_CHARS` 字符。
- 相关文件：`backend/summary.py`（`write_article`）、`frontend/src/components/MarkdownText.tsx`。

## 3. 速度优化

- 默认模型从 `deepseek-chat` 切到 `deepseek-flash`。
- 有字幕时不下载音频；无字幕时只下载 bestaudio，直接解码，不再先转 MP3。
- 转写、总结、文案按 URL + 模型 + prompt 版本缓存到 `data/cache/summary-cache/`。
- 总结先返回，文案在独立线程后台生成，不阻塞总结阅读。
- 同一视频第二次打开直接命中缓存。

## 4. 笔记仓库（Markdown + SQLite 索引）

- 每次 AI 总结自动创建 `data/library/*.md`，生成中先写 `.drafts/`，完成后原子改名。
- 文件带 AI 摘要、出处、平台、UP 主、时长；正文含摘要、要点、章节、完整文案、可折叠原始转写。
- 同一视频按 `source_url` 去重，重新生成覆盖同一篇。
- SQLite `data/library.sqlite3` 只做元数据索引；删库后扫描 Markdown 重建。
- 独立 `#/library` 页面：搜索、状态筛选、预览、多选下载 zip、多选删除到回收站。
- 批量 zip 带 `index.md` 清单；回收站保留 7 天，可恢复。
- 相关文件：`backend/library.py`、`backend/note_writer.py`、`frontend/src/pages/LibraryPage.tsx`。
- 库表：`notes(id, title, file_path, draft_path, source_url, ai_summary, status, ...)`。

## 6. 长视频总结格式异常的修复

`deepseek-flash` 在长转写/长文案场景会先产生较多 reasoning token。之前 `max_tokens=1800` 时，思考过程可能把额度用完，最终 `content` 为空或不完整 JSON，界面在 93% 报「AI 返回的总结格式不正确」。

修复内容：

- 总结 JSON 解析改为 `JSONDecoder.raw_decode`，忽略模型前后添加的解释文字。
- 总结/修复调用 `max_tokens=6000`，分段笔记 `2500`，完整文案 `8000`（分段 `6000`）。
- JSON 解析失败时自动让模型修复一次；仍失败则降级为「一句话总结」，不让整次转写白费。
- 记录 `finish_reason`、`reasoning_content` 长度，方便后续排查。
- 用 15:19 的缓存转写实测：总结 17 秒、完整文案 43 秒，均成功。

## 7. 配置变化

新增环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SUMMARY_ARTICLE_ENABLED` | `true` | 是否生成 AI 完整文案 |
| `SUMMARY_ARTICLE_MAX_CHARS` | `24000` | 整理稿最多处理字符数 |
| `SUMMARY_CACHE_TTL_SECONDS` | `2592000` | 缓存保留时间 |
| `CLIPDOCK_CACHE_DIR` | `./data/cache` | 下载临时文件与 AI 缓存 |
| `CLIPDOCK_LIBRARY_DIR` | `./data/library` | Markdown 仓库目录 |
| `CLIPDOCK_LIBRARY_DB` | `./data/library.sqlite3` | 仓库索引 |
| `LIBRARY_TRASH_TTL_DAYS` | `7` | 回收站保留天数 |

`SUMMARY_MODEL` 默认值改为 `deepseek-flash`；旧 `.env` 建议同步修改。
