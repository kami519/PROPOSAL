## 1. 产品定位

一个给自己用的视频下载页：**粘贴链接 → 解析 → 选清晰度 → 下载**。

不做公开收费、不做登录、不做订阅、不做价格页。页面尽量短，只保留下载、平台说明和常见问题。

## 2. 目标与边界

### 目标

- 电脑和手机浏览器都能直接使用。
- 支持从中文分享文案中提取视频链接。
- 720P、1080P、最高可用画质、仅音频都可以直接下载。
- 下载过程可暂停、继续、取消。
- AI 视频总结：字幕优先，无字幕时本地转写。
- AI 完整文案：把转写整理成带标题、段落、列表的 Markdown，可复制/下载。
- 结果页阅读模式：左侧内容、右侧 300px 媒体栏；转写/总结/文案缓存。
- 部署轻量：下载任务无数据库，笔记仓库用 SQLite 索引；无账号体系。

### 不做

- 不提供付费墙、邀请码、价格页、订单或真实支付。
- 不做批量下载、用户历史、多租户。
- 不破解 DRM、不绕过登录/会员权限、不下载私密内容。
- 不长期保存用户视频。

## 3. 视觉方向

参考 `https://ai.codefather.cn/painting` 的白底、蓝色点缀、大留白和卡片呼吸感，但不复制其瀑布流布局。

- 主色：暖纸白 `#F5F3ED`
- 强调色：电光蓝 `#1E5BFF`
- 荧光绿 `#D9FF63` 只用于成功、完成和高亮
- 记忆点：「收片回执」结果卡，像一张快递单
- 首页：Logo、下载框、平台索引、FAQ、页脚，不展示营销长文

## 4. 技术方案

| 层 | 方案 |
| --- | --- |
| 前端 | React 19 + Vite 8 + TypeScript，原生 CSS |
| 后端 | Python 3.13 + FastAPI + Uvicorn |
| 解析/下载 | yt-dlp Python API |
| 合并/转码 | imageio-ffmpeg 自带 ffmpeg |
| AI 转写 | faster-whisper（本地 CPU） |
| AI 总结 | OpenAI 兼容接口 |
| 状态 | 内存 Job Store / Summary Store，临时目录 |
| 部署 | 单端口托管前端静态文件；下载任务无数据库，笔记仓库 SQLite 索引 |

## 5. 主要流程

```text
粘贴链接 / 分享文字
  → 提取 URL
  → yt-dlp 解析元数据和可用画质
  → 选择 720P / 1080P / 最高画质 / 音频
  → 创建下载任务
  → 下载、合并、自动保存
  → 可选：AI 总结
```

AI 总结：

```text
已有字幕 → 直接总结
无字幕   → 下载音频 → 本地 Whisper 转写 → 总结
```

## 6. 页面结构

1. 顶栏：品牌、支持平台、常见问题、私人工具标识
2. 首屏：一句主标题、下载框、平台快捷标签
3. 平台索引：支持情况与限制说明
4. FAQ：失败原因、隐私、手机使用、4K 权限、AI 总结、版权
5. 页脚：私人使用与合规提示

结果卡包含：封面、标题、作者、时长、画质选择、下载进度、暂停/继续/取消、AI 总结入口。

## 7. 实施阶段

### Phase 1（已完成）

- 单链接解析和下载。
- 720P / 1080P / 最高画质 / 音频。
- 剪贴板容错和中文分享文字提取。
- 真实进度、ffmpeg 合并、自动保存。
- 桌面与手机响应式。

### Phase 1.1（已完成）

- 下载暂停、继续、取消。
- AI 视频总结（字幕优先 + Whisper 回退）。
- 私人免费版：移除 Pro 付费墙、邀请码、价格页和 Pro 弹窗。

### Phase 1.2（已完成）

- 阅读模式：左侧总结/文案，右侧 300px 媒体栏；移动端单列。
- AI 完整文案：把转写整理成 Markdown，可复制/下载。
- 转写/总结/文案缓存；音频流直接解码，不再先转 MP3。
- 默认模型切换到 `deepseek-flash`。

### Phase 1.3（已完成）

- Markdown 笔记仓库：每篇带 AI 摘要、出处、完整文案和原始转写。
- 独立 `#/library` 页面：搜索、预览、多选下载 zip、多选删除到回收站。
- SQLite 只做可重建索引，Markdown 仍是唯一正文来源。
- 生成中先写草稿，完成后原子落盘；同一视频按 URL 去重。

### 后续可选

- 批量链接。
- 字幕下载与字幕翻译。
- 访问密码 / 反向代理认证。
- 持久化日志。

## 8. 风险与边界

1. YouTube 在当前网络需要 cookies；B 站实测最稳定。
2. 平台风控、登录、地区限制、DRM 都会导致失败。
3. 4K/HDR 通常是登录/会员权益；服务端没有权限时只能拿到 1080P，页面会说明。
4. 文件先落到服务器再转发给浏览器，默认 4GB 上限。
5. 下载任务在内存中，重启会丢失进行中的任务；笔记仓库持久化在 data/library，日志目前只输出到终端。
6. 私人使用；如果暴露到公网，建议增加访问控制。
7. 本地 Whisper 首次使用需要下载模型，CPU 转写长视频较慢。

## 9. 已确认决策

1. 品牌名：收片 CLIPDOCK。
2. 视觉：暖纸白 + 电光蓝 + 荧光绿 + 收片回执。
3. 私人免费使用，不做付费转化。
4. 首期单链接，批量与字幕下载后置。
5. 前台不展示 yt-dlp、GitHub 等第三方技术信息，技术说明保留在文档中。
6. 下载任务无数据库、无登录、无支付；笔记仓库用可重建的 SQLite 索引。

## 10. 验收基线

- 公开 B 站链接能解析并下载 720P / 1080P。
- 1080P 不需要邀请码。
- 手机 390px 无横向滚动。
- 暂停后能继续，取消后临时文件被清理。
- 配置模型 Key 后能生成完整 AI 总结。
- 登录、DRM、4K 权限不足时有明确中文提示。
